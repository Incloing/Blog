ONE CONNECTION, YOUR WORDS

连接写作空间

使用仅能访问 Incloing/Blog 的 GitHub 令牌。令牌只留在当前页面的内存中，刷新或断开连接后需要重新填写。

  1. 在 GitHub 创建细粒度令牌 ↗
  2. Repository access 选择 Only select repositories，仅勾选 Blog。
  3. Repository permissions 的 Contents 设置为 Read and write，生成后复制到下方。

请勿把令牌发到聊天里。此处不会保存令牌，也不会写入仓库。

删除本机草稿？

这只会删除当前浏览器内的草稿，网站上已发布的文章会保留。
